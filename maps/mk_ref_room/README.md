# mk_ref_room: Reference Room

A stone room recreated from a single screenshot of stock mohdm1, as the worked
example for [docs/from-reference.md](../../docs/from-reference.md). Every
position in [`build.py`](build.py) was measured from the picture with
`mohkit.camera`, and the materials were chosen with `mohkit looks-like` and
`mohkit swatches`. It's a test scene, not a playable DM map.
