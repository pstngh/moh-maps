# MOHAA/OpenMoHAA map research and generated maps

This repository contains stock map-source references, generated playable maps,
and a cumulative production system for creating better MOHAA/OpenMoHAA maps.

Start with [`docs/README.md`](docs/README.md). The mandatory production
workflow is [`docs/MAP-GENERATION-PLAYBOOK.md`](docs/MAP-GENERATION-PLAYBOOK.md).

## Repository layout

- `aa/`, `sh/`, `bt/`: stock map-source corpus used for format and design
  research.
- `generated/`: reproducible generated-map sources, tools, reports, and tested
  PK3 packages.
- `docs/`: production rules, asset knowledge, templates, and the historical
  research log.

The reference corpus is evidence, not a default visual template. Each new map
should choose materials, lighting, geometry, and props deliberately for its
own setting.
